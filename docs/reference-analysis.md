## 网页适配

- 电脑鼠标、触摸屏、键盘左右键 + 空格均可发射。
- 原创宠物：叶鳍灵感的泡泡灵、头顶花芽的花芽灵、长耳星梦灵感的眠眠灵；图鉴随进度解锁。
- 暂停、重新开始、3 倍加速、瞄准提示、音效开关、浏览器全屏。
- 本地保存已解锁关卡、最佳星级、最少弹珠、宠物图鉴、累计快乐积分。
- 同屏最多 5 颗弹珠；单颗弹珠最多停留 14 秒，避免接近水平角度造成长期等待。
- 星级：使用不超过初始弹珠 45% 获得 3 星，不超过 75% 获得 2 星，其余通关为 1 星。奖励为 20 + 星级 × 10。

## 复刻边界

目标是覆盖视频可见的主要功能和玩法，而非声称精确达到一个无法量化的百分比。视频未展示设置菜单、失败界面和收藏系统的完整行为；本项目提供相应网页操作与失败重试，图鉴是原创宠物的配套功能。广告插页不纳入游戏玩法。耐久数值、收集数量、碰撞参数与奖励平衡为根据画面进行的可玩化重建。
