# 宠物弹珠 · Pet Marbles

[**点击开始玩 →**](https://jdb156158.github.io/PetMarbles/)

[![宠物弹珠游戏预览](docs/preview.png)](https://jdb156158.github.io/PetMarbles/)

一颗弹珠，一场小奇遇。根据参考视频重建的反弹收集小游戏，宠物与全部画面均为原创绘制。无需安装、无需账号，电脑和手机均可游玩。

## 怎么玩

1. 在紫色弹珠台内按住并拖动，虚线会预览第一段碰撞路径，松开发射。
2. 借助侧墙与弹板连续命中目标。耐久归零后收集，完成本关配额即可通关。
3. 弹珠耗尽且场上无弹珠时可重试。使用更少弹珠获得更高星级。

键盘：点击弹珠台后，`←` / `→` 瞄准，`空格` / `Enter` 发射。支持暂停、重开、3 倍加速、瞄准提示、音效和全屏。手机顶部的 `♡` 与 `?` 可打开宠物图鉴和玩法说明。

## 包含内容

- 8 个可通关关卡，覆盖泳池、糖果、森林三组主题。
- 矩形与收腰场地、反弹板、耐久障碍、多个数量收集目标。
- 饼干箱、星星泡泡、蛋糕、冰块、莓果树、叶子泡泡、木板、甜甜螺。
- 3 位原创宠物：泡泡灵、花芽灵、眠眠灵。
- 连击反馈、碰撞音效、彩带结算、星级与累计快乐积分。
- 自动保存解锁进度、最佳记录和宠物图鉴。

第 8 关根据视频结尾的预览补全；关卡数值与物理参数为可玩化重建。详见[视频拆解及实现范围](docs/reference-analysis.md)。

## 本地运行与验证

纯 HTML / CSS / JavaScript / Canvas，无运行时依赖、无打包步骤、无外部素材请求。

```sh
python3 -m http.server 4183 --directory dist
# 浏览器访问 http://localhost:4183
npm test
```

`npm test` 验证收集配额、碰撞、耐久、弹珠消耗、失败条件、路径预览，以及全部关卡在预算内通过真实物理模拟的可达性。

安装 Playwright 后，可启动本地服务并运行 `node scripts/verify-browser.cjs` 执行真实浏览器的逐关发射与交互验收；可用 `TEST_URL` 指向其他环境，`CHROME_PATH` 指定 Chrome 路径，`PLAYWRIGHT_PATH` 指定已有 Playwright 包。截图写入 `docs/`。

推送到 `main` 后，GitHub Actions 会运行规则测试并发布 `dist/` 到 GitHub Pages。
